Dans `todo.md` (projet Kablix), conserver les traits de séparation `---` et en ajouter un après chaque lot d'items traités.

**Why:** L'utilisateur s'en sert pour repérer les vagues de demandes successives ; supprimer un `---` lui fait perdre ce repère.

**How to apply:** Quand je coche des items en `[x]`, ne jamais retirer un `---` existant ; ajouter un `---` entre le nouveau lot terminé et le précédent si la frontière manque.
