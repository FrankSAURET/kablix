# NTC 热敏电阻

![NTC 热敏电阻](../../img/composants/ntc.webp)

**负** 温度系数热敏电阻：温度升高时电阻 **减小**。裸的两引脚元件，需接成分压器使用。正温度系数的版本见 [PTC](ptc.md)。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **1** | 端子 1 |
| **2** | 端子 2（无极性） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `r25` | 25 °C 时的电阻 (Ω) | 10 000 |
| `beta` | B 值 (K) | 3950 |
| `tmin` | 滑块最低温度 (°C) | -55 |
| `tmax` | 滑块最高温度 (°C) | 125 |

## 仿真中

仿真时元件上会出现一个 **温度滑块**，范围由 `tmin` 和 `tmax` 限定。电阻遵循 B 值公式：

```
R = r25 x exp( beta x (1/(T+273.15) - 1/298.15) )
```

使用默认值时：25 °C 下为 10 kΩ，0 °C 下约 34 kΩ，50 °C 下约 3.6 kΩ。

## 用法

- 把 NTC 与一个与 `r25` 同量级的固定电阻（10 kΩ 的 NTC 配 10 kΩ）接成 **分压器**，中点接模拟输入。
- `beta` 取自热敏电阻的数据手册（3380、3950、4050…）。
- 无极性元件：两根引脚没有区别。

---

*Kablix 元件 — B 值模型 `R = r25 x exp(beta x (1/T - 1/T25))`。*
