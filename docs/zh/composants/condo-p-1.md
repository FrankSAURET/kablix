# 有极性电容（钽）

![有极性电容（钽）](../../img/composants/condo-p-1.webp)

滴状钽电容，**有极性**。RC 特性与无极性电容相同 — 指数充放电，约 5·R·C 后完成 — 但不能接反。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **+** | 正极（引脚 `2`） |
| **−** | 负极（引脚 `1`），接地 |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `ctype` | 类型：无极性 / 有极性 / 电解 | 有极性 |
| `value` | 标称值，单位法拉（可用 `m`、`µ`、`n`、`p` 后缀） | 10µ |
| `vmax` | 最大额定电压 (V) | 16 |
| `angle` | 方向 (0/90/180/270°) | 0 |

## 用法

- 从元件库放置 **电容**，再把 `ctype` 设为 “有极性”：钽电容在元件栏中没有单独的条目。
- 注意极性：**+** 接高电位，**−** 接地。
- 输入的数值会印在元件外壳上。
- 可放在需要尖峰电流的负载（舵机、电机）旁作储能，配合 100 nF 去耦电容使用。
- 钽电容不耐过压：`vmax` 要留出充足余量。
