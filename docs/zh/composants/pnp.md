# 三极管 PNP（通用）

![通用 PNP 三极管](../../img/composants/pnp.webp)

**PNP** 双极型三极管的原型：与 NPN 相比一切都是反的。发射极接电源 **+**，负载在集电极一侧，通过 **把基极拉低** 来控制。

## 引脚

引脚按图形顺序命名为 **1**、**2** 和 **3** — 而不是 E/B/C。因此修改电极分配不会重命名任何引脚，**导线永远不会断开**。

| 引脚 | 作用 |
|--------|------|
| **1** | 第一只引脚（默认为发射极） |
| **2** | 第二只引脚（默认为基极） |
| **3** | 第三只引脚（默认为集电极） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `pkg` | 元件封装 | TO-92 |
| `e` | 发射极所在引脚（1、2 或 3） | 1 |
| `b` | 基极所在引脚（1、2 或 3） | 2 |
| `c` | 集电极所在引脚（1、2 或 3） | 3 |
| `gain` | 电流增益 β（1 位小数） | 100 |
| `text` | 封装上的印字（每输入一行印一行） | PNP |
| `vcemax` | Vce 最大值 (V) | 40 |
| `icmax` | Ic 最大值 (A) | 0.6 |

一只引脚只能对应 **一个** 电极：把发射极分配给已被集电极占用的引脚时，两者会 **互换**。

## 仿真

- 当 **基极为低电平、发射极为高电平**（发射极接 +）时导通。
- 它能通过的电流上限为 **增益 × Ib**，与 NPN 相同。
- 作为高端开关连接：为另一端接地的负载供电。

## 用法

- 注意用 5 V 开发板驱动的情况：0 V 输出确实能把基极拉低，但 3.3 V 的 “高电平” 输出无法关断发射极接 5 V 的 PNP。入门时用 NPN 更简单。
- 要导入你自己的图形，请使用 **元件创建器**（仿真模型选 “双极型三极管”）。
