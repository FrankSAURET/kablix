# LED 灯带

![LED 灯带](../../img/composants/led-strip.webp)

可寻址 RGB LED 灯带，**可扩展**：LED 数量是一个属性。为了放进图纸，灯带被画成**螺旋盘绕**，输入端在外侧，通过三根或四根导线连到接线端。**接线端固定**在左上角：LED 数量改变时，螺旋向下和向右增长，接线端不动。

## 引脚

接线端取决于协议。

| 引脚 | 作用 | 协议 |
|--------|------|-----------|
| **GND** | 地 | 全部 |
| **5V** | 电源 (+) | 全部 |
| **DIN** | 数据输入（单线） | WS2811、WS2812(B) / SK6812 |
| **DI** | 数据 | APA102、WS2801 |
| **CI** | 时钟 | APA102、WS2801 |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `leds` | LED 数量（最少 1，无上限） | 10 |
| `protocol` | 灯带协议，见下 | WS2812(B) / SK6812 |
| `colorOrder` | 线上的颜色顺序：RGB、BRG、GRB（仅 WS2801） | RGB |

提供的四种协议：

- **单线 — WS2811**：3 个引脚（GND、5V、DIN）。颜色顺序 **RGB**，帧尾停顿 **300 µs**。
- **单线 — WS2812(B) / SK6812 (NeoPixel)**：3 个引脚（GND、5V、DIN）。颜色顺序 **GRB**，帧尾停顿 **300 µs**。
- **SPI — APA102 (DotStar)**：4 个引脚（GND、5V、DI、CI）。SPI 模式 0：起始帧（32 个 0 位），然后每个 LED 32 位（`111` + 5 位亮度、蓝、绿、红），最后是结束帧。
- **SPI — WS2801**：4 个引脚（GND、5V、DI、CI）。SPI 模式 0：每个 LED 24 位，无起始帧。时钟停顿 **> 500 µs** 即锁存颜色。颜色顺序可调（默认 RGB，另有 BRG、GRB）。

切换协议会改变接线端：已接在消失引脚上的导线会丢失。

## 使用

- DIN 接开发板的数字引脚，5V 和 GND 接电源。
- 仿真中，**熄灭**的 LED **保持白色**，**点亮**的 LED **带有光晕**，颜色与其相同，越亮光晕越大。
- LED 从**输入端**（螺旋外侧）到**末端**（中心）依次编号：LED 0 在最外侧。
- **单线**：NeoPixel 库（`Adafruit_NeoPixel`、`neopixel`），可用于任意数字引脚。
- **SPI**：灯带监听开发板的**硬件 SPI 总线**（DI 接 MOSI，CI 接 SCK），例如 MicroPython 的 `machine.SPI` 或 Arduino 的 `SPI.transfer`。软件模拟的 SPI（手动翻转引脚）不会被解码。SPI 灯带不能级联。
- 灯带像灯环一样可以**级联**：它从公共帧中取走 `leds` 个颜色。
