# 拨动开关

![拨动开关](../../img/composants/slide-switch.webp)

两位置单刀双掷 (SPDT) 开关：公共端在两个端子之间切换。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **1** | 位置 A |
| **2** | 公共端 |
| **3** | 位置 B |

## 用法

- 公共端 (2) 接引脚；一个位置接地，另一个接 +。
- 仿真时单击即可切换。
