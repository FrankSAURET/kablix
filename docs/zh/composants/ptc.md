# PTC 热敏电阻

![PTC 热敏电阻](../../img/composants/ptc.webp)

**正** 温度系数热敏电阻：电阻随温度 **升高**。可用作线性传感器（KTY 类探头）或可自恢复的过流保护元件。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **1** | 端子 1 |
| **2** | 端子 2（无极性） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `r25` | 25 °C 时的电阻 (Ω) | 2000 |
| `tc` | 温度系数 (%/°C) | 0.79 |
| `tmin` | 滑块最低温度 (°C) | -55 |
| `tmax` | 滑块最高温度 (°C) | 125 |

## 仿真中

仿真时元件上会出现一个 **温度滑块**，范围由 `tmin` 和 `tmax` 限定。电阻遵循线性规律：

```
R = r25 x ( 1 + (tc/100) x (T - 25) )
```

使用默认值时：25 °C 下为 2 kΩ，0 °C 下约 1.6 kΩ，50 °C 下约 2.4 kΩ。

## 用法

- 接法与 [NTC](ntc.md) 相同：与一个接近 `r25` 的固定电阻接成分压器，中点接模拟输入。
- 与 NTC 不同，当 PTC 位于分压器上端时，读到的电压随温度 **升高**。
- 无极性元件：两根引脚没有区别。

---

*Kablix 元件 — 线性模型 `R = r25 x (1 + tc/100 x (T - 25))`。*
