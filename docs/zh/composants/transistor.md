# 三极管

![三极管](../../img/composants/transistor.webp)

TO-92 或 TO-220 封装的三极管。在 Kablix 中它是一个 **受控开关**：很小的基极电流就能让大得多的集电极电流通过，比例由型号的 **增益** 决定。而 MOSFET 由 **电压** 控制：它的栅极是绝缘的，不消耗电流。

元件库中只有一个 “三极管”：**型号在属性中选择**，列表会随着你设置的条件逐步缩小。

## 选择型号

放置元件后，检查器会显示 **选择器**：

| 条件 | 作用 |
|-----------|--------|
| **类型** | NPN、PNP、NPN 达林顿、PNP 达林顿、N 沟道 MOSFET |
| **封装** | TO-92 或 TO-220 |
| **Ic 最大值至少**（MOSFET 为 **Id 最大值**） | 只保留能承受该电流的型号 |
| **Vce 最大值至少**（MOSFET 为 **Vds 最大值**） | 只保留能承受该电压的型号 |
| **增益至少** | 只保留增益不低于该值的型号 — 双极型 |
| **Rds(on) 至多** | 只保留电阻低于该值的型号 — MOSFET |

最后两项不会同时出现：MOSFET 没有增益，双极型没有 Rds(on)。选择器只显示适合所选系列的那一项。

下方是 **符合条件的型号** 列表：单击即可设定型号，检查器恢复正常显示。**更换三极管…** 按钮随时可以重新打开选择器。**最近新增的型号** 以 **蓝色** 显示。

| 系列 | 型号 |
|--------|--------|
| NPN | PN2222A, 2N3904, 2N4401, 2N5551, BC337, S8050, BC547, BC548, BC639, MPSA42, BD911 |
| PNP | 2N2907A, 2N3906, 2N4403, 2N5401, BC327, S8550, BC557, BC558, BC640, MPSA92, BD912 |
| NPN 达林顿 | BC517 |
| PNP 达林顿 | BC516 |
| N 沟道 MOSFET | BS170, IRF530, IRL540N, IRLZ34N, IRL1004 |

BD911、BD912、IRF530、IRL540N、IRLZ34N 和 IRL1004 采用 **TO-220** 封装：功率封装（IRL1004 最高 130 A）。

IRL540N、IRLZ34N 和 IRL1004 是“逻辑电平”MOSFET：Vgs(th) 最大值 2 V，在 Pico 的 3.3 V 下即可导通（IRF530 需要 3.5 V，仍会截止）。

列表的最后一项始终是所选系列的 **自定义型号**（“自定义 NPN”、“自定义 N 沟道 MOSFET”…）：已设置的条件会预先填入，之后 **一切仍可修改** — 增益或 Rds(on)、最大电压和电流、封装印字、电极分配。

## 引脚

双极型元件（NPN、PNP、达林顿）有 E、B、C：

| 引脚 | 作用 |
|-----|------|
| **E** | 发射极 — 经典 NPN 电路中接地 |
| **B** | 基极 — 控制端，一定 要串联电阻 |
| **C** | 集电极 — 接被开关的负载（继电器、电机、LED） |

MOSFET 有 G、D、S：

| 引脚 | 作用 |
|-----|------|
| **G** | 栅极 — 电压控制，绝缘：没有电流流入 |
| **D** | 漏极 — 接被开关的负载 |
| **S** | 源极 — N 沟道器件接地 |

同一系列内引脚名称 **从不** 改变：因此更换型号不会使导线断开。改变的是承载每个电极的 **物理引脚** — 从平面一侧看，BC5xx 系列是 C-B-E，而 2Nxxxx 是 E-B-C，BD911 是 B-C-E。检查器会在参数下方显示引脚排列，每根导线都跟随它的电极。

## 属性

| 属性 | 作用 | 默认值 |
|----------|------|---------|
| `ref` | 所选型号 | *（空：打开选择器）* |
| `pkg` | 封装 — TO-92 或 TO-220 | to92 |
| `gain` | 电流增益 (β) — 自定义双极型 | 100 |
| `rdson` | Rds(on) (Ω) — 自定义 MOSFET | 0.5 |
| `vcemax` | Vce 最大值（MOSFET 为 Vds 最大值），单位 V — 自定义型号 | 40 |
| `icmax` | Ic 最大值（MOSFET 为 Id 最大值），单位 A — 自定义型号 | 0.6 |
| `text` | 封装印字 — 自定义型号 | NPN |
| `e` / `b` / `c` | 各电极所在引脚 — 自定义双极型 | 1 / 2 / 3 |
| `g` / `d` / `s` | 各电极所在引脚 — 自定义 MOSFET | 1 / 2 / 3 |
| `angle` | 方向 (0/90/180/270°) | 0 |

对于商用型号，这些数值来自厂家数据手册，不能修改：要自己设置，请使用 **自定义型号**。

## 仿真

- NPN 在 **基极为高、发射极为低** 时导通；PNP 在基极为低、发射极为高时导通。N 沟道 MOSFET 的导通条件与 NPN 相同：栅极高，源极低。
- 通过的电流上限为 **增益 × Ib**：这就是全部模型。因此要让它 **饱和** — 如果下游负载需要更多电流，就无法工作（风扇不转，继电器不吸合）。
- Vbe = 0.7 V，Vce(sat) = 0.2 V。基极 **不加电阻** 连接时一定饱和…… 但会烧坏真实的三极管：请加基极电阻。
- **达林顿**：两个 PN 结串联，因此 **Vbe = 1.4 V**，**Vce(sat) = 0.9 V**。它的增益极大 (30 000)，极小的基极电流就足够了 — 这正是它的意义所在。
- **MOSFET**：栅极绝缘，因此 **没有基极电流，也没有增益**。仅靠电压就能打开沟道，沟道随后可通过最高 **Id 最大值** 的电流。因此不需要栅极电阻也能工作（在真实电路中，它用来减缓开关边沿）。

## 用法

- 典型计算：用增益 35 的三极管驱动 40 mA 的继电器线圈，需要 Ib ≥ 40 / 35 ≈ 1.2 mA。在 5 V 下，1 kΩ 基极电阻提供 (5 − 0.7) / 1000 ≈ 4.3 mA：充分饱和。
- 基极电阻太大（100 kΩ）→ Ib = 43 µA → Ic 最大 ≈ 1.5 mA：负载永远启动不了。这是仿真中要留意的典型错误。
- 驱动继电器时 **必须加续流二极管**（阴极朝 +）：否则断电时的尖峰会损坏三极管。
