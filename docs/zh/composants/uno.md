# Arduino Uno

![Arduino Uno](../../img/composants/uno.webp)

ATmega328P 开发板：14 个数字 I/O（6 个 PWM）、6 个模拟输入、USB。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **0–13** | 数字 I/O（~ = PWM） |
| **A0–A5** | 模拟输入 |
| **5V / 3.3V / VIN** | 电源 |
| **GND** | 地 |
| **AREF / RESET** | ADC 参考电压 / 复位 |

## 用法

- 用 **K** 按钮查看完整引脚图（海报）。
- 5 V 逻辑电平。
