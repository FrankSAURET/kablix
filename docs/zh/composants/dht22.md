# DHT22 温湿度传感器

![DHT22 温湿度传感器](../../img/composants/dht22.webp)

单总线数字温湿度传感器。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **VCC** | 电源 (+) |
| **SDA** | 数据（单总线） |
| **NC** | 不连接 |
| **GND** | 地 |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `temperature` | 温度 (°C) | 22 |
| `humidity` | 湿度 (%) | 50 |

## 用法

- SDA 接数字引脚（10 kΩ 上拉）。
- DHT 库：约每 2 秒读取一次。
- 仿真时，两个滑块可 **实时** 设置温度和湿度：下一次读取即返回新值。
- 如果显示的数值似乎不变，请检查程序两次读取之间是否至少间隔 2 秒：读得太快时，DHT 库会返回 **缓存的值**，与真实传感器完全一样。
