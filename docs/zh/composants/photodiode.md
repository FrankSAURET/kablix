# 光电二极管

![光电二极管](../../img/composants/photodiode.webp)

透明封装的 **裸** 两引脚光电二极管：通过的电流与接收到的光成正比。原理与 [光电三极管](phototransistor.md) 相同，但 **没有放大作用**：同样的光照下，光电二极管通过的电流约小一百倍。作为交换，它更快、更准确。

它工作在 **反向** 状态：阴极接正极一侧，阳极接负极一侧。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **K** | 阴极 — 电压较高的一侧 |
| **A** | 阳极 — 接地一侧 |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `eemax` | 滑块的最大辐照度 (mW/cm²) | 5 |
| `ron` | 最大辐照度时的电阻 (Ω) | 20 000 |
| `rdark` | 完全黑暗时的电阻 (Ω) | 100 000 000 |
| `ee` | 初始辐照度 (mW/cm²) | 1 |

## 仿真中

仿真时元件上会出现一个 **亮度滑块**：从全黑到 `eemax`。电流随接收的光线变化；把它看作一个电阻时，阻值的变化方向正好相反：

```
R = ron x eemax / ee
```

限制在 `ron`（全亮）与 `rdark`（全黑）之间。使用默认值时：5 mW/cm² 下为 20 kΩ，1 mW/cm² 下为 100 kΩ，黑暗中为 100 MΩ。

## 用法

- **必须接电阻。** 光电二极管单独使用时只会让电流时大时小：没有东西把这个电流变成可读取的电压。
- 常用接法：`5V → K ... A → 中点 → 100 kΩ 电阻 → GND`，中点接模拟输入。光线越亮，电压越高。
- 反向接法（`5V → 电阻 → 中点 → K ... A → GND`）：光线越暗，电压越高。
- 负载电阻要 **大**（通常 100 kΩ）：电流很小，需要大电阻才能从中得到电压。
- 注意方向：阴极接正极一侧。接反的话，二极管会一直导通，光线就不起作用了。

## 报告的故障

Kablix 在仿真开始时检查电路，在两种情况下会标出该元件：

- **没有串联电阻**：只有一个引脚接到电源轨，或者一个都没有。没有分压器，也就没有东西可测。
- **直接跨接在电源上**：两个引脚直接接到正极和地，中间什么都没有。
