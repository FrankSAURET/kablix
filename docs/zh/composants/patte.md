# 蜘蛛腿

![蜘蛛腿](../../img/composants/patte.webp)

带 **2 个独立内部舵机** 的关节式机器人腿：**基节 (coxa)** 让腿 **在地面上** 摆动（前/后），**膝节 (patella)** 让腿 **抬起和放下**。两者在机械上嵌套 — 膝节跟随基节转动，就像真正的腿一样。用于搭建多腿的六足或蜘蛛机器人，接到 [PCA9685 PWM 驱动板](pca9685.md) 的通道上。

这 **正是 [蜘蛛机器人](araignee.md) 的腿**：股骨和胫骨是同样的零件，单独安装并以 **3D**（等轴测视图）显示 — 这是同时展示两种运动的唯一方式，一个在地面平面内，另一个在竖直平面内。脚下的 **投影** 让人一眼看出脚的高度。

元件栏类别：**系统**。

## 引脚

图形左侧的 **接插件** 有两个 3 线端子，每个关节一个 — **Coxa**（紫色）和 **Patella**（绿色）— 与普通舵机一样。每个端子上的三个 **金色方块** 就是连接点；图形上没有写它们的名称，悬停时会显示在 **提示气泡** 中：

| 引脚            | 作用                    |
| --------------- | ----------------------- |
| **coxa.GND**    | 基节地                  |
| **coxa.V+**     | 基节电源 (+)            |
| **coxa.PWM**    | 基节控制信号            |
| **patella.GND** | 膝节地                  |
| **patella.V+**  | 膝节电源 (+)            |
| **patella.PWM** | 膝节控制信号            |

（按图形顺序，从上到下）

两个关节在电气上 **相互独立**：例如，完全可以用微控制器引脚驱动基节，用 PCA9685 的通道驱动膝节。

## 属性

| 属性          | 作用                                                                                 | 默认值    |
| ------------- | ------------------------------------------------------------------------------------ | --------- |
| `pulsemin`    | 0° 时的脉宽 (µs)，两个关节共用                                                       | `500`     |
| `pulsemax`    | 180° 时的脉宽 (µs)，两个关节共用                                                     | `2500`    |
| `speed`       | 全速转一整圈 360° 所需时间 (s)，0 = 瞬间到位                                          | `2`       |
| `revcoxa`     | 基节舵机 **反向安装**：同样的设定值会让它向另一方向转                                 | 未勾选    |
| `revpatella`  | 膝节舵机 **反向安装**                                                                | 未勾选    |
| `zerocoxa`    | 程序给基节发送 0° 时 **绘制** 的角度（−360 到 +360°）                                | `0`       |
| `zeropatella` | 膝节的同一设置                                                                       | `0`       |

两个反向复选框是 **安装** 设置，而不是程序设置：舵机拧在哪一侧，同样的设定值就会向相反方向转。勾选后，仿真对该关节使用 **180 − 角度** — 代码仍然发送 “30°”。

两个 **零位** 是同一设置的另一半：舵盘是按花键装回去的，很少能正好落在想要的位置。`zerocoxa = 20` 表示 “程序发送 0° 时，腿已经指向 20°”。偏移量在反向 **之后** 加上：两者叠加，一个决定方向，一个决定原点。

### 各角度的含义

| 角度     | 基节（地面摆动）           | 膝节（脚的高度）                                            |
| -------- | -------------------------- | ----------------------------------------------------------- |
| **0°**   | 向一侧转四分之一圈         | 腿 **收起**，脚缩在身体下方                                 |
| **90°**  | 静止位置                   | 胫骨 **竖直**：脚着地，机器人站立                           |
| **180°** | 向另一侧转四分之一圈       | 腿 **水平伸直**，腹部着地                                   |

## 用法

- `coxa.PWM` 和 `patella.PWM` 分别接到支持 PWM 的微控制器引脚，或接到 PCA9685 的通道（`coxa.V+`/`coxa.GND` 和 `patella.V+`/`patella.GND` 接相应的舵机端子）。
- `Servo` 库（Arduino）：每个关节一个对象，先 `attach()`，再 `write(角度)`。
- 四足蜘蛛：放置 4 个该元件，每个接到 PCA9685 的 2 个通道。完整的机器人也有现成的：见 [蜘蛛机器人](araignee.md)。

示例测试：`patte-uno` 和 `patte-pico`（`testkablix` 文件夹）。
