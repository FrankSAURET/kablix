# 蜘蛛机器人

![蜘蛛机器人](../../img/composants/araignee.webp)

一个完整的 **四足机器人**：一个底盘和 **4 条腿，每条腿 2 个关节**（基节和膝节），即 **8 个舵机**。所有电子器件都 **装在机身内部** — 一块 **Pico W**、一块 [PCA9685 PWM 驱动板](pca9685.md) 和电池：8 个舵机在内部接好线，永远不会出现在图纸上。

**机器人没有任何引脚：无需接线。** 它 *就是* 开发板。把它放到图纸上会自动把 **Pico W** 选为目标开发板，你写的程序就在它里面运行，与在裸 Pico W 上完全一样。开发板画在底盘背上 — 这是告诉你代码在哪里运行的标志。

机器人以 **3D**（等轴测视图）绘制：基节在地面上摆动，膝节抬起腿。

> 这几乎就是 **真实的机器人**：它的零件就是激光切割的 PMMA 零件 — 夹层结构的机身、每条腿的股骨和胫骨、就位的舵机和电路板。长度、基节间距、机身高度和行程全部来自图纸；元件本身不固定任何尺寸。因此重画一个零件就会改变屏幕上的机器人，而无需修改代码。

元件栏类别：**系统**。

## 引脚

**没有。** I²C 总线、电源和 8 个舵机都在机器人内部：外部无需连接任何东西。

## 属性

| 属性                         | 作用                                                                          | 默认值     |
| ---------------------------- | ----------------------------------------------------------------------------- | ---------- |
| `ad0` … `ad5`                | 机载 PCA9685 的六个地址焊盘状态（勾选 = 焊盘 **高**）                          | 全部勾选   |
| `pulsemin`                   | 0° 对应的脉宽 (µs)，八个舵机共用                                               | `500`      |
| `pulsemax`                   | 180° 对应的脉宽 (µs)，八个舵机共用                                             | `2500`     |
| `speed`                      | 全速转一整圈 360° 所需时间 (s)，0 = 瞬间到位                                   | `2`        |
| `chcoxa0` … `chpatella3`     | 该舵机 **所插** 的 PCA9685 通道（0 到 15）                                     | **空**     |
| `revcoxa0` … `revpatella3`   | 舵机 **反向安装**：同样的设定值会让它向另一方向转                              | 未勾选     |
| `zerocoxa0` … `zeropatella3` | 程序给该舵机发送 0° 时 **绘制** 的角度（−360 到 +360°）                        | `0`        |

### 三十三个设置，分放在五个抽屉里

机器人的设置比任何其他元件都多，因此分为 **五个可折叠的栏目**，选中时 **全部收起**。

| 栏目                           | 设置内容                                                                                            |
| ------------------------------ | --------------------------------------------------------------------------------------------------- |
| **配置 16 路舵机板**           | 机载 PCA9685 的六个地址焊盘                                                                         |
| **舵机接线**                   | 八个舵机各自插在 PCA9685 的哪个输出上 — 需要填写，不做任何假设                                       |
| **反转舵机**                   | 八个安装方向复选框。转动方向必须与真实模型一致，代码才能通用                                         |
| **设置舵机零位**               | 八个舵盘偏移量。原因同上。                                                                          |
| **舵机参数**                   | 0° 和 180° 的脉宽、旋转时间                                                                         |

在各栏目上方、所有抽屉之外，显示计算出的 **I²C 地址**：这是最常要找的信息，不应该费力才能看到。

机载 PCA9685 的地址 **与真实板子一样** 设置，勾选六个焊盘 **AD0 到 AD5**。全部勾选 — Grove 模块的出厂设置 — 得到 **0x7F**，这是机器人的默认地址。完整的计算见 [PCA9685 帮助页](pca9685.md)。

八个关节与 [单条腿](patte.md) 的角度规则相同：基节 90° = 静止（腿朝外，沿其底盘角的轴线方向），膝节 90° = **胫骨竖直，机器人站立，四只脚着地**。180° 让腿沿股骨方向伸直，0° 向另一侧收起。

### 舵机脉宽

八个舵机完全相同，因此只有 **一个比例**：`pulsemin` 是表示 0° 的脉宽，`pulsemax` 是表示 180° 的脉宽。默认值是机器人所用舵机的数值（**500 – 2500 µs**，SF90 数据手册）。

这个设置决定 **中间** 角度是否准确。比例错误在两端看不出来 — 1500 µs 在几乎任何比例下都是 90°，两端又有限位 — 但 130° 的设定值很可能会偏，机器人就摆不出程序要求的姿势。

### 反向安装的舵机

在真实底盘上，八个舵机并不都拧在同一侧：同样的设定值，有些会向相反方向转。勾选相应关节的复选框（`revcoxa0` = 左前基节，`revpatella3` = 右后膝节…），仿真就对该舵机使用 **180 − 角度**。

这是 **安装** 设置，而不是程序设置：代码仍然发送 “30°”，由机械结构决定往哪边转。

> 要在仿真中重现一个已组装好的机器人的行为而不重写其程序，这一点必不可少。

### 每个舵机的零位

**原点** 也是同样的道理。在真实模型上，八个舵机没有一个与相邻的装得完全一样，即使程序在所有地方发送相同的角度，机器人最后还是歪的。

两个方向各允许转一整圈（**−360 到 +360°**，精确到度）。偏移量在反向 **之后** 施加：复选框决定方向，零位决定原点，两者在同一关节上叠加。这里程序同样不需要任何改动 — 你描述的是底盘。

## PWM 通道

每个关节都要指明其舵机插在 **机载 PCA9685 的哪个输出** 上。**放置机器人时这八个框都是空的**：不做任何假设，由你描述自己的接线。

| 关节                           | 属性                     |
| ------------------------------ | ------------------------ |
| **左前** 基节 / 膝节           | `chcoxa0` / `chpatella0` |
| **右前** 基节 / 膝节           | `chcoxa1` / `chpatella1` |
| **左后** 基节 / 膝节           | `chcoxa2` / `chpatella2` |
| **右后** 基节 / 膝节           | `chcoxa3` / `chpatella3` |

### 每个舵机一个小框，0 到 15

**舵机接线** 抽屉中排着八个 **两个字符宽的小框** — 没有微调箭头，也没有 **+** / **−** 按钮：输出编号不是靠反复试出来的，而是从板子上读出来再填进去。

> 取值 **0 到 15**，对应板上的 **1 到 16** 标记：标 **1** 的输出是通道 **0**。

**同一通道不能用两次。** 输入已被其他关节占用的编号时会被拒绝 — 输入框闪红并恢复原值。超过 15 也一样。

**仿真开始时**，会报告留空的输入框：状态栏中显示消息，机器人周围出现红框。仿真仍然运行 — 已接线的关节会动，留空的保持不动。

这是继方向和零位之后的第三个 **安装** 设置：程序本身不变。在代码中写通道 0，属性里填了 `0` 的那个关节就会动。

右侧的腿与左侧的腿 **镜像** 对称，与真实机器人一样：同样的膝节角度会让两侧对称弯曲。

## 用法

- 把机器人 **单独** 放到图纸上：开发板会自动切换为 **Pico W**，无需任何接线。
- 在程序中打开一条 I²C 总线（`I2C(0, sda=Pin(0), scl=Pin(1))`）：这是机器人的 **内部** 总线，无论你选哪些引脚编号，都能连到机载 PCA9685。
- 像控制图纸上的 PCA9685 一样控制各通道：把预分频设为 50 Hz，然后写入所需的脉宽（500 µs = 0°，1500 µs = 90°，2500 µs = 180°）。
- 只想让一条腿动时，只需写入它的两个通道：从未写入的通道对应的关节保持不动。

示例测试：`araignee-pico`（`testkablix` 文件夹）。
