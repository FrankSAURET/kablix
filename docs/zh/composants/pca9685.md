# 16 路 PWM 驱动板 (PCA9685)

![16 路 PWM 驱动板 (PCA9685)](../../img/composants/pca9685.webp)

Seeed **16-Channel PWM Driver** Grove 模块（型号 108020102），基于 NXP **PCA9685**：通过 I²C 总线提供 16 路 12 位 PWM 输出，用于驱动舵机或 LED。16 个舵机接口 **P1 到 P16**（通道 0 到 15）。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **SDA / SCL** | I²C 总线（左侧 Grove 接口） |
| **VCC / GND** | 芯片逻辑电源（Grove 接口） |
| **V+ / GND.2** | 舵机电源端子（**Power In**，右侧） |
| **PWM0…PWM15** | 各舵机接口的信号（P1 = PWM0 … P16 = PWM15） |
| **Pn.5V / Pn.GND** | 各舵机接口的电源（红/黑） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `ad0` … `ad5` | 板上六个地址焊盘的状态（勾选 = 焊盘 **高**） | 全部勾选 |

## I²C 地址

![板子背面的地址焊盘](../../img/composants/pca9685%20-%20dessous.webp)

地址不是从列表中选择的：它 **与真实板子一样** 设置，在检查器中勾选六个焊盘 **AD0 到 AD5**（在模块背面，见上图）。得到的 7 位地址显示在复选框下方，其值为：

```
地址 = 1 A5 A4 A3 A2 A1 A0
```

第 6 位在模块上 **接高电平**，第 7 位不存在：因此地址范围从 **0x40**（所有焊盘为低）到 **0x7F**（全部为高）。

| AD5 | AD4 | AD3 | AD2 | AD1 | AD0 | 地址 |
|:---:|:---:|:---:|:---:|:---:|:---:|---------|
| 0 | 0 | 0 | 0 | 0 | 0 | `0x40` |
| 0 | 0 | 0 | 0 | 0 | 1 | `0x41` |
| 0 | 0 | 0 | 0 | 1 | 0 | `0x42` |
| … | … | … | … | … | … | … |
| 1 | 1 | 1 | 1 | 1 | 1 | `0x7F` |

> Grove 板出厂时 **所有焊盘均为高 → 0x7F**（与 Adafruit 的裸 PCA9685 模块不同，后者焊盘为低 → 0x40：取消勾选全部六个复选框即可模拟它）。这就是你的程序要使用的地址。同一总线上有多块板子时，给每块设置不同的焊盘组合。

## 必须外接电源

舵机 **不** 由板子的逻辑部分供电：必须在 **V+ / GND.2** 端子（Power In）上接一个 **[实验室电源](alim.md)**（*测量仪器* 类别），设为 **约 5 V**，并提供 **足够的电流**。

- 没有这个电源（或超出 4.5–5.5 V 范围，或电流不足）时，输出 **不会动作** — 芯片仍会在 I²C 上应答，与真实板子完全一样。
- 每个舵机约耗电 0.2 A：请相应调整电源的 *最大输出电流*。

## 用法

- SDA/SCL/VCC/GND 接微控制器，V+/GND.2 端子接电源。
- 把舵机（PWM/V+/GND）插到 **P1…P16** 接口上。
- PCA9685 产生 16 路 50 Hz 的 PWM 信号；0.5–2.5 ms 的脉冲对应 0–180° 的角度。
- 通过 I²C 访问 PCA9685 的寄存器（MODE1、PRESCALE、LED0_ON_L…），或使用专用库（Adafruit PCA9685、`grove_16_channels_pwm`…）。
