# NeoPixel 灯环

![NeoPixel 灯环](../../img/composants/led-ring.webp)

可寻址 RGB LED (WS2812) 组成的灯环。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **VCC** | 电源 (+) |
| **GND** | 地 |
| **DIN** | 数据输入 |
| **DOUT** | 数据输出 |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `pixels` | LED 数量 | 16 |

## 用法

- DIN 接数字引脚。
- 适合做环形效果（旋转、仪表）。
- 仿真时，**熄灭的 LED 保持白色**（与真实板子一样），**点亮的 LED 带有** 自身颜色的 **光晕**，越亮光晕越大。
- **亮度较低** 时，外壳保持 **带色调的白色**，变淡的是光晕：WS2812 会漫射光线，永远不会变暗。
- 灯环可以像单个像素一样 **级联**：DOUT 接下一个元件的 DIN，它占用公共数据帧中 `pixels` 个颜色。
