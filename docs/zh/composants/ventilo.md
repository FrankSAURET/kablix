# 风扇

![风扇](../../img/composants/ventilo.webp)

直流风扇。所加电压越高，扇叶转得越快；也可以用 **PWM** 控制。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **+** | 电源（红线） |
| **−** | 地（黑线） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `voltage` | 额定电压 (V) | 5 |
| `current` | 消耗电流 (A) | 0.85 |
| `angle` | 方向 (0/90/180/270°) | 0 |

## 用法

- **严格** 的物理模型：只有电源真的能提供 `current` 时风扇才会启动。低于额定转速的 30 % 时它不转，就像真实电机只嗡嗡响却不转。
- **单片机引脚不够用**：最多只能提供 40 mA，而风扇需要 850 mA。请用三极管或 MOSFET 开关外部电源。
- PWM 控制：在控制引脚上用 `analogWrite()`（Arduino）或 `PWM`（MicroPython）；扇叶转速随占空比变化。
- 在电机两端并联续流二极管，吸收断电时的尖峰。
- **在屏幕上读转速**：3000 rpm 时，7 片扇叶的风扇每秒有 350 片扇叶从你眼前掠过 — 看到的只是闪烁，改变电压也看不出任何变化。因此风扇以 **慢动作** 旋转：根据工况每秒 1.5 到 7 片扇叶。这不是真实转速，重要的是它的 **变化** — 加速和减速一眼就能看出。**扇叶模糊** 效果则强调转速范围的上半部分。
