# 电解电容

![电解电容](../../img/composants/condo-p-2.webp)

铝电解电容，**有极性**。电容家族中容量大的成员：指数充放电，约 5·R·C 后完成。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **+** | 正极（引脚 `2`） |
| **−** | 负极（引脚 `1`），外壳上的浅色条纹标示 |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `ctype` | 类型：无极性 / 有极性 / 电解 | 电解 |
| `value` | 标称值，单位法拉（可用 `m`、`µ`、`n`、`p` 后缀） | 100µ |
| `vmax` | 最大额定电压 (V) | 16 |
| `angle` | 方向 (0/90/180/270°) | 0 |

## 用法

- 从元件库放置 **电容**，再把 `ctype` 设为 “电解”：它在元件栏中没有单独的条目。
- 注意极性：浅色条纹标示 **−** 极。接反时，真实的电解电容会鼓包甚至爆裂。
- 电源滤波：稳压器输出端用 100 µF 到 1000 µF。
- 时间常数较长：10 kΩ 配 100 µF 时 τ = 1 s，充满需 5 s — 在绘图器中清晰可见。
