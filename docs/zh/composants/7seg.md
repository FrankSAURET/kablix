# 7 段数码管

![7 段数码管](../../img/composants/7seg.webp)

七段数码管（带小数点），用于显示数字和简单符号。1 到 4 位，共阴极或共阳极。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **A–G** | 7 个段 |
| **DP** | 小数点 |
| **COM / COM.1 / COM.2** | 公共端（阴极或阳极） |
| **DIG1–DIG4** | 各位的公共端（多位） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `color` | 颜色 | 红 |
| `common` | 公共端（阴极/阳极） | 阴极 |
| `digits` | 位数 (1/2/4) | 1 |
| `colon` | 时钟冒号 | — |

## 用法

- 每个段各串一个电阻。
- 共阴极：COM 接地，各段接 +；共阳极：相反。
- 多位：动态扫描（每次快速点亮一位）。
- **时钟模式**（`colon`，4 位）：小数点让位给中间的两个点，只要有任意一个 DP 被驱动，它们就会亮。要让它们一直亮着，可以把 DP 经电阻接到开发板的 **+ 电源轨**（3.3 V 或 5 V）— 无需占用微控制器引脚：仿真会考虑这种接法。
