# 蜂鸣器

![蜂鸣器](../../img/composants/buzzer.webp)

有源压电蜂鸣器：只要两端加上电压就会发声。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **1** | + 端（正极） |
| **2** | – 端 |

## 用法

- + 端接输出引脚，– 端接地。
- 用 `tone()`（Arduino）产生不同频率。
