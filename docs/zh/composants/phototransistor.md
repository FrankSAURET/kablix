# 光电三极管

![光电三极管](../../img/composants/phototransistor.webp)

透明封装的 **裸** 两引脚光电三极管：接收的光越强，通过的电流越大。比 [LDR](ldr.md) 更快、更灵敏，但 **有极性** — 集电极接正极一侧，发射极接负极一侧。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **c** | 集电极 — 电压较高的一侧 |
| **e** | 发射极 — 接地一侧 |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `eemax` | 滑块的最大辐照度 (mW/cm²) | 5 |
| `ron` | 最大辐照度时的电阻 (Ω) | 200 |
| `rdark` | 完全黑暗时的电阻 (Ω) | 10 000 000 |
| `ee` | 初始辐照度 (mW/cm²) | 1 |

## 仿真中

仿真时元件上会出现一个 **亮度滑块**：从全黑到 `eemax`。光电三极管的电流随接收的光线变化；把它看作一个电阻时，阻值的变化方向正好相反：

```
R = ron x eemax / ee
```

限制在 `ron`（全亮）与 `rdark`（全黑）之间。使用默认值时：5 mW/cm² 下为 200 Ω，1 mW/cm² 下为 1 kΩ，黑暗中为 10 MΩ。

## 用法

- **必须接电阻。** 光电三极管单独使用时只会让电流时大时小：没有东西把这个电流变成可读取的电压。
- 常用接法：`5V → 10 kΩ 电阻 → 中点 → c ... e → GND`，中点接模拟输入。光线越暗，电压越高。
- 反向接法（`5V → c ... e → 中点 → 电阻 → GND`）：光线越亮，电压越高。
- 模拟输入读到的电压取决于电路中实际的分压。

## 报告的故障

Kablix 在仿真开始时检查电路，在两种情况下会标出该元件：

- **没有串联电阻**：只有一个引脚接到电源轨，或者一个都没有。没有分压器，也就没有东西可测。
- **直接跨接在电源上**：两个引脚直接接到正极和地，中间什么都没有。在强光下，电路会使电源短路。

---

*Kablix 元件 — 模型 `R = ron x eemax / ee`，限制在 `ron` 与 `rdark` 之间。*
