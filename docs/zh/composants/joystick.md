# 模拟摇杆

![模拟摇杆](../../img/composants/joystick.webp)

带内置按键的双轴（X/Y）摇杆。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **VCC** | 电源 (+) |
| **VERT** | 垂直轴（模拟） |
| **HORZ** | 水平轴（模拟） |
| **SEL** | 按键（按下） |
| **GND** | 地 |

## 用法

- VERT 和 HORZ 接两个模拟输入，SEL 设为 `INPUT_PULLUP`。
- 静止时两轴读数约为 512（中间）。

## 仿真中

- **摇杆**：用鼠标拖动，可在两个轴上得到连续的值。松开后会弹回中心 — 除非按住 **Ctrl**（Mac 上为 Cmd），这会 **锁定** 位置。
- **箭头**：单击四个箭头之一，按住期间给出满偏。键盘方向键效果相同。
- **SEL 按键**：单击摇杆中心。**Ctrl+单击**（Mac 上为 Cmd+单击）会 **锁定** 按下状态 — 便于测试长按，而不用一直按着鼠标；普通单击即可松开。
