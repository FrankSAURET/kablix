# 按钮

![按钮](../../img/composants/button.webp)

12 mm 自复位轻触按钮。松开时电路断开；按下时连通两个触点。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **1.l / 1.r** | 第一个触点（左/右，始终相连） |
| **2.l / 2.r** | 第二个触点（左/右） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `color` | 颜色 | 绿 |
| `label` | 按钮下方的文字 | — |
| `key` | 键盘快捷键 | — |

## 用法

- 常用接法：一个触点接设为 **`INPUT_PULLUP`** 的引脚，另一个接地 → 按下时读到 `LOW`。
- 反向接法：一个触点接 **+5 V**，另一个接设为 **`INPUT`** 的引脚，并从该引脚接一个 **10 kΩ** 电阻到地 → 按下时读到 `HIGH`。没有这个电阻，引脚在松开时处于悬空状态，读数毫无意义。
- **Ctrl+单击**：保持按钮按下。
- 要做 **消抖** 处理。
