# 无极性电容

![无极性电容](../../img/composants/condo-np.webp)

塑料薄膜电容，无极性。与电阻串联构成 RC 电路：其两端电压按指数规律上升和下降，约 5·R·C 后充满（或放完）。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **1** | 端子 1 |
| **2** | 端子 2（无极性：两者没有区别） |

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `ctype` | 类型：无极性 / 有极性 / 电解 | 无极性 |
| `value` | 标称值，单位法拉（可用 `m`、`µ`、`n`、`p` 后缀） | 100n |
| `vmax` | 最大额定电压 (V) | 400 |
| `angle` | 方向 (0/90/180/270°) | 0 |

## 用法

- 输入的数值会 **印在元件外壳上**（`10µ`、`100n`…）。
- 电源去耦：100 nF，尽量靠近芯片的 VCC 引脚。
- RC 测量：从设为 `HIGH` 的引脚经电阻充电，在模拟输入上读取上升过程。τ = R·C，5τ = 充满。
- 也可以利用输入引脚的 **内部上拉**（Arduino 或 Pico）：上拉电阻（Kablix 中为 65 kΩ；RP2040 数据手册给出 50 到 80 kΩ）充当充电电阻，无需外接电阻。在 Pico 上，内部 **下拉** 同样可以给电容放电。
- 元件库只列出一个 **电容**：类型（薄膜、钽、电解）在 `ctype` 属性中选择。
- 修改 `ctype` 不会重命名引脚：已画好的导线保持不变。
- **绘图器** 无需写一行代码就能显示指数曲线：每个加到模拟输入上的电压都由内部探针绘制，并以转换器通道和引脚命名（`ADC0 (A0)`、`ADC0 (GP26)`…）。把几条 RC 支路并联在同一个驱动引脚上，它们的曲线就能在同一张图上比较。
