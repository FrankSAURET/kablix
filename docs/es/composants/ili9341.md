# Pantalla TFT (ILI9341)

![Pantalla TFT (ILI9341)](../../img/composants/ili9341.webp)

Pantalla TFT a color de 240×320 (SPI). Muestra texto, imágenes y gráficos.

## Pines

| Pin | Función |
|--------|------|
| **VCC / GND** | Alimentación |
| **SCK / MOSI / MISO** | Bus SPI |
| **CS** | Selección del chip |
| **D/C** | Datos/Comando |
| **RST** | Reinicio |
| **LED** | Retroiluminación |

## Uso

- Bus SPI. Bibliotecas Adafruit_ILI9341 / TFT_eSPI.
- En simulación, el lienzo se decodifica y se dibuja.
