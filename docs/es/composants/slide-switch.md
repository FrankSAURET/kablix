# Interruptor deslizante

![Interruptor deslizante](../../img/composants/slide-switch.webp)

Interruptor SPDT de 2 posiciones: el común conmuta entre dos bornes.

## Pines

| Pin | Función |
|--------|------|
| **1** | Posición A |
| **2** | Común |
| **3** | Posición B |

## Uso

- Común (2) al pin; una posición a masa, la otra a +.
- Haga clic para conmutarlo en simulación.
