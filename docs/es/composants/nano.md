# Arduino Nano

![Arduino Nano](../../img/composants/nano.webp)

Placa compacta ATmega328P (el mismo núcleo que el Uno), en formato de protoboard.

## Pines

| Pin | Función |
|--------|------|
| **0–13** | E/S digitales (~ = PWM) |
| **A0–A7** | Entradas analógicas |
| **5V / 3.3V / VIN** | Alimentación |
| **GND** | Masas |

## Uso

- Las mismas capacidades que el Uno, en más pequeño.
- A6/A7: solo entradas analógicas.
