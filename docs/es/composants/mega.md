# Arduino Mega 2560

![Arduino Mega 2560](../../img/composants/mega.webp)

Placa ATmega2560: 54 E/S digitales (15 PWM), 16 entradas analógicas, 4 UART.

## Pines

| Pin | Función |
|--------|------|
| **0–53** | E/S digitales |
| **A0–A15** | Entradas analógicas |
| **5V / 3.3V / VIN** | Alimentación |
| **GND** | Masas |

## Uso

- Para proyectos que necesitan muchos pines.
- Patillaje completo con el botón **K**.
