# Zumbador

![Zumbador](../../img/composants/buzzer.webp)

Zumbador piezoeléctrico activo: emite un sonido mientras se aplica tensión entre sus bornes.

## Pines

| Pin | Función |
|--------|------|
| **1** | Borne + (positivo) |
| **2** | Borne – |

## Uso

- Borne + a un pin de salida, borne – a masa.
- `tone()` (Arduino) para generar frecuencias.
