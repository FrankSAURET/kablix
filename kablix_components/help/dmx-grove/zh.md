# Grove DMX512

![Grove DMX512](dmx-grove.webp)

Grove DMX512 扩展板（Seeed Studio）：一个 **SP3485** 线路驱动器，把开发板的 UART 变成 **3 针 XLR** 插座上的 DMX512 输出。库元件：通过元件管理器安装。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **SIG** | 串行输入，接开发板的发送引脚 |
| **VCC** | +5 V 电源 |
| **GND.1** | 地，Grove 一侧 |
| **NC** | 不连接 |
| **+** | XLR 的 Data+（针 3） |
| **−** | XLR 的 Data−（针 2） |
| **GND.2** | XLR 的屏蔽（针 1） |

两个地，所以有两个名称：图形上两边都写着 “GND”，网表用 `GND.1` 和 `GND.2` 区分它们 — 就像继电器的 `Com.1` / `Com.2`。

## 接线

- **SIG** 接发送引脚：Uno 上为 `1` (TX)，Mega 上为 `1` / `18` / `16` / `14`，Pico 上为 `GP0`。使用 `DmxSimple` 时，任何引脚都可以（默认为 3）。
- **VCC** 接 +5 V，**GND.1** 接地。
- XLR 一侧，`+` / `−` / `GND.2` 接 [灯具](spot.md)，后续灯具依次串接。

## 仿真

这块板本身没有行为：它只是一个线路驱动器。但电路的意义由它决定 — Kablix 从接到 **SIG** 的引脚出发，找到共用这对线的所有灯具，并把它们监听的通道数据应用上去。与开发板或灯具断开后，什么都不会亮。

使用 **逻辑分析仪** 时，夹在 **SIG** 或 **+** 上的 [探头](sonde-logique.md) 显示驱动这块板的引脚信号，夹在 **−** 上的探头显示同一信号的 **反相**：这就是 DMX 的差分线对，− 线总是与 + 线相反。要解码 − 通道，请在其设置中勾选 **反相**：它就会像 + 一样被读取。在边栏中，**+** 和 **−** 通道显示的是线路驱动器的输出电压，高电平 **3.7 V**、低电平 **1.1 V**（SN75176A 数据手册的数值），而不是开发板的电压；**SIG** 通道仍显示开发板的电压。

DMX 数据 **不会** 送到串口监视器：一帧有 513 个二进制字节，每秒一帧，控制台会被淹没。
