# Grove 光线传感器

![Grove 光线传感器](grove-light-sensor.webp)

一块带有 “电子眼” 的小电路板。光线越强，通过的电流越大：电路板把这个电流转换成电压，并从一根导线输出。天黑时自动点亮的小夜灯、在暗处自动调暗的屏幕，用的都是这种传感器。

库元件：通过元件管理器安装，不在原始元件栏中。

## 引脚

这是一个四线 Grove 接口，按线缆顺序：

| 引脚 | 作用 |
|--------|------|
| **GND**（黑） | 地 |
| **VCC**（红） | 电源，3.3 V 或 5 V |
| **NC** | 不连接 — 这根线未使用 |
| **SIG**（黄） | 输出，接到一个 **模拟输入**（A0、GP26…） |

输出不是开关量：它是一个平缓上升的电压。因此必须接到能测量电压的输入，而不是普通的数字引脚。

## 输出的含义

| 光线 | **SIG** 上的电压 |
|---------|---------------------|
| 完全黑暗 | 接近 **0 V** |
| 明亮的房间 | 大约一半 |
| 强烈阳光 | 接近电源电压 |

在程序中，Arduino 上 `analogRead(A0)` 在黑暗中返回 **0**，强光下返回 **1023**；Pico 上 `ADC.read_u16()` 返回 **0** 到 **65535**。用一个阈值就能在天黑时开灯：

```c
if (analogRead(A0) < 200) { /* 天黑了：开灯 */ }
```

## “满量程照度” 属性

检查器中显示一个以 **勒克斯 (lx)** 为单位的值（默认 **500 lx**）。勒克斯是接收光照的单位：一支蜡烛只有几勒克斯，照明良好的书桌约 500 勒克斯，晴天户外超过 10 000 勒克斯。

这个值表示 **传感器在多大照度时到达量程终点**，也就是输出电压达到最大值的时候。修改它，仿真滑块的刻度会随之改变：设为 10 000 lx，滑块就从 0 到 10 000。

## 仿真

仿真时，元件上有一个 **照度** 滑块，刻度从 **0** 到满量程值。拖动它：`SIG` 引脚的电压会立即线性跟随 — 0 lx 对应 0 V，满量程对应开发板的电源电压（5 V 或 3.3 V）。程序在下一轮循环读到变化。

真实的传感器响应并不完全是线性的，而且它对绿光比对红光或蓝光略敏感。因此在真实电路中，要先读出关键的数值（黑暗的房间、明亮的房间），再确定阈值。

## 注意

- 该传感器 **不** 输出勒克斯值：它输出的是电压。要读取真实的勒克斯值，需要直接测量的传感器（例如 I²C 总线上的 TSL2561）。
- 不要让它正对着它所控制的灯：灯亮了会照到它，它又会把灯关掉，如此反复。要避免这种无休止的闪烁，可以把两者分开，或让开灯阈值和关灯阈值之间留出差距。
