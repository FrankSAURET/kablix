# 土壤湿度传感器

![土壤湿度传感器](soil-moisture-sensor.webp)

两根插进花盆泥土里的探针。干燥的土壤导电差，湿润的土壤导电好：传感器测量电流通过的难易程度，并以电压的形式从一根导线输出。这是自动浇水系统用的传感器。

库元件：通过元件管理器安装，不在原始元件栏中。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **+**（红） | 电源，Arduino 上为 5 V，Pico 上为 3.3 V |
| **−**（黑） | 地 |
| **S**（信号） | 输出，接到一个 **模拟输入**（A0、GP26…） |

输出不是开关量：它是一个平缓上升的电压。因此必须接到能测量电压的输入，而不是普通的数字引脚。

## 输出的含义

| 土壤 | 导电情况 | **S** 上的电压 |
|-------|--------------------|-------------------|
| 干燥 | 差 | 接近 **0 V** |
| 潮湿 | 一般 | 大约一半 |
| 湿透 | 好 | 接近电源电压 |

在程序中，Arduino 上 `analogRead(A0)` 在干燥时返回 **0**，湿透时返回 **1023**；Pico 上 `ADC.read_u16()` 返回 **0** 到 **65535**。用一个阈值就能决定是否浇水：

```c
if (analogRead(A0) < 350) { /* 太干了：浇水 */ }
```

## 仿真

仿真时，元件上有一个 **土壤湿度** 滑块，刻度从 **0 到 100 %**。拖动它：`S` 引脚的电压会立即线性跟随 — 0 % 对应 0 V，100 % 对应开发板的电源电压（5 V 或 3.3 V）。程序在下一轮循环读到变化。

真实的传感器既不会完全降到零，也不会完全升到最大值：每个传感器的范围都不一样。因此在真实电路中，要先读出两个极端值（探针悬空、探针插在一杯水里），再确定阈值。

## 注意

- 不要让探针在土壤中 **一直通电**：流过的电流会腐蚀探针（氧化）。在真实电路中，只在读数时用一个输出引脚给传感器供电。
- 单靠土壤的导电性并不能可靠地衡量浇水情况：相同湿度下，不同的土壤导电性不同。
