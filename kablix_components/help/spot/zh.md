# DMX PAR 38 投光灯

![DMX PAR 38 投光灯](spot.webp)

通过 **DMX512** 控制的 PAR 38 LED 投光灯（Contest）。它监听线路，显示其通道上收到的颜色。库元件：通过元件管理器安装，不在原始元件栏中。

## 引脚

| 引脚 | 作用 |
|--------|------|
| **GND** | XLR 线缆屏蔽（针 1） |
| **−** | Data−（针 2） |
| **+** | Data+（针 3） |

线对的 **两根** 线都必须接到接口板：只接了 Data+ 的灯具无法被控制 — 它只接了一半，仿真中保持熄灭。

## 属性

| 属性 | 作用 | 默认值 |
|-----------|------|--------|
| `address` | DMX 地址，1 到 512。灯具从这里开始读取四个通道：红、绿、蓝、效果 | 1 |

多个灯具可以共用同一条线路，各自使用自己的地址：这正是 DMX 的基本原理。地址相同的两个灯具颜色相同。

## 通道

| 通道 | 作用 | 取值 |
|-------|------|---------|
| 地址 | 红 | 0 到 255 |
| 地址 + 1 | 绿 | 0 到 255 |
| 地址 + 2 | 蓝 | 0 到 255 |
| 地址 + 3 | 效果 | **0 到 189**：亮度（0 = 熄灭，189 = 全亮）；**190 到 250**：闪烁，从 1 Hz (190) 到 10 Hz (250)；**251 到 255**：不变，按发送的颜色显示 |

效果通道为 0 时，无论颜色如何，灯具都 **不亮**：只发送红、绿、蓝的程序也必须设置第四个通道。

## 接线

开发板 → [Grove DMX512](dmx-grove.md) → XLR 线缆 → 灯具。后续灯具在同一线对上 **串接**。

## 仿真

Kablix 解码开发板发出的数据帧，用收到的颜色点亮灯具的 LED，并带有光晕。两种方式都能识别：

- **硬件 UART** — Arduino 端 `Serial.begin(250000, SERIAL_8N2)`，Pico 端 `machine.UART(0, 250000, stop=2)`，BREAK 和 MAB 由程序产生；
- **位操作库** — `DmxSimple`，它不使用 UART，而是在普通引脚（默认为 3）上产生数据帧：线路按边沿逐一解码。

颜色通道为 0 时对应的 LED 熄灭；三个都为 0 时灯具熄灭。闪烁跟随仿真时间：仿真暂停时闪烁也会停住。
